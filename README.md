# EVIDEN

**Construye con evidencia.**

Plataforma de información verificable sobre costos, trámites y normativa para construir en México.

## MVP 0.1

Primera jurisdicción: **Pachuca de Soto, Hidalgo**  
Primer caso: **casa habitación unifamiliar · obra nueva · 2026**

## Principio de datos

> Fuente → evidencia → dato estructurado → regla → cálculo → resultado

EVIDEN no presenta como hecho un dato normativo que no pueda rastrearse a una fuente identificable y versionada.

## Estado actual

- Modelo de dominio v0.2 definido.
- Fuentes oficiales iniciales incorporadas.
- Procedimientos y requisitos principales de obra nueva habitacional estructurados.
- Tarifas de uso de suelo 2026 incorporadas desde el Decreto 590-LXVI.
- Tarifas operativas de construcción y terminación incorporadas desde RUTS y cotejadas donde ya existe fuente primaria localizada.
- Motor de cálculo determinista inicial en desarrollo.
- Tests preparados con Vitest.
